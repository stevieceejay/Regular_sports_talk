# Sports Chat

Sports Chat is a simple web page for a sports conversation idea. It is made for regular fans who want to ask questions, understand what happened in a game, and talk about sports without overly formal explanations.

## What is on the page?

- The opening section introduces Sports Chat and the idea behind it.
- The “Why this exists” section explains the goal: creating an AI sports chatbot for everyday fans.
- The “Early look” section shows a product mockup and asks visitors what they would want to ask first.
- The footer closes the page with the message “Regular fans. Better questions.”

## Feedback form

Visitors can type a question or comment in the feedback box. The form:

- Shows a live character count up to 500 characters.
- Clears the status message while someone is typing.
- Shows “Add a comment first.” if the form is submitted without text.
- Shows a thank-you message after valid feedback is submitted.
- Clears the form and resets the character count after submission.

Feedback is only handled on the page for now. It is not sent to a server or saved anywhere.

## Files

- `index.html` contains the page content and feedback form.
- `styles.css` controls the layout and visual design.
- `script.js` adds the character counter and feedback form behavior.
